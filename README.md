# Kovalenko Creatives

A static portfolio site showcasing the apps I've built.

- `index.html` — page layout
- `styles.css` — styling (light and dark mode)
- `projects.js` — the list of projects shown on the page; edit this to add or change work
  - Each project's `slides` are the pictures visitors cycle through (arrows, dots or swipe). A slide can be an image path such as `'images/rhythm-1.png'`, or HTML for a mock screen. Put screenshots in an `images/` folder.
- `app.js` — renders the project cards and category filters

Open `index.html` in a browser to preview. No build step needed, so it can be hosted as-is on GitHub Pages, Cloudflare Pages or Netlify.
